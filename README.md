## What we hold to

**Never invent.** A gap is recorded as a gap. An unstated field stays unstated.
"Not known" is a valid answer and the only honest one when it's true.

**Log everything.** Every decision an agent makes is recorded with what it was
based on. Where something is uncertain, the system says so rather than smoothing
over it.

**Stay stoppable.** Every agent has a kill switch and an audit trail. Autonomy
without a stop is not autonomy, it's an incident.
